## Public contract and frozen canonical oracle
MemoryManager.admit_evidence_source(*, principal: MemoryPrincipal,
envelope: SanitizedEvidenceEnvelope, receipt: SanitizedEvidenceReceipt) -> EvidenceSourceAdmissionReceipt.
Exact registered principal/actor==subject and all existing S1 validation are mandatory.
No new authority, analysis_lineage, job/outbox, execution Run or disclosure grant.

C is UTF-8 JSON, sorted keys, ensure_ascii=False, separators(',', ':'), allow_nan=False.
H is SHA-256 lower hex. Receipt ID is 'source-admission:' +
H(C({domain:'memory.evidence.source-admission.id.v1',payload:{subject,source_ref,envelope_hash,admission_receipt_id,admission_receipt_hash}})).
Receipt hash is H(C({domain:'memory.evidence.source-admission.receipt.v1',payload:receipt.to_json()})).
to_json includes schema_version=1, receipt_id,evidence_id,subject,source_ref,source_hash,sanitized_hash,
envelope_hash,admission_receipt_id,admission_receipt_hash,accepted_at; excludes receipt_hash.
accepted_at is finite nonnegative SDK clock, normalized float; replay preserves first clock.
Receipt immutable, exact field/hash binding. No job identifiers. All previous hash algorithms unchanged.
Independent vectors in tests/fixtures/source-admission-v1.json were generated by stdlib alone before product implementation;
ASCII/non-ASCII+zero-time vectors include canonical bytes, ID and final hash. Tests load constants, never product-derived expectations.

## Storage and read boundary
New immutable source_admission_receipts plus existing evidence_envelopes/items/links only.
Atomic admission has zero INSERT/UPDATE/DELETE to jobs/outbox/analysis batches/attempts/apply heads/cognitive records.
Reuse existing principal registry, no placeholder owner admitted via this port.
Cross-mode detection under BEGIN IMMEDIATE before any evidence writes on all shared keys:
(subject,source_ref), evidence_id, Host admission receipt ID. Both directions raise
MemoryIdempotencyConflict('evidence_admission_mode_conflict'); no implicit promotion, cleanup or lineage patch.
Source replay must match complete envelope AND complete Host receipt. Changed same-mode bindings conflict.
Existing full-mode replay semantics/receipt bytes and USER analysis flow stay unchanged.

Registration and history must reconstruct and validate either real admission kind. IngestedEvidenceRecord.ingestion_receipt
becomes an explicit union of the old full receipt and new source-only receipt (no fake job-bearing receipt).
Existing full-mode mutation span authorization remains unchanged: source-only does not create an analysis claim or permit
implicit mutation promotion. Canonical state manifest must include the new immutable receipt table.
Schema7.2 is fresh-only for this candidate: reject prior7.1 DBs unchanged, rather than silently convert full-ingested
assistants or clean jobs. Retain frozen7.0 DDL/checksum definitions for existing tooling; no new migration promised.
Host uses fresh candidate Memory DB; original immutable Host S1s are reused, never restamped.
